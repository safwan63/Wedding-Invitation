# Noora & Ifsul Wedding Invitation 💍

Welcome to the digital wedding invitation for **Dr. Noora Fathima & Dr. Ifsul Hashim**.

This beautifully crafted web application serves as a digital gateway for our guests, offering them an immersive experience leading up to our special day.

## ✨ Features

- **Interactive Envelope Opening:** A custom CSS and JS animation giving the classic feeling of opening a physical invitation.
- **Cinematic Hero Section:** Background video header setting a loving and elegant mood.
- **Scratch-to-Reveal Date:** An engaging scratch-card feature revealing the wedding date.
- **Live Countdown:** A real-time countdown timer to the wedding day (19 September 2026).
- **Venue Details:** Embedded links and clear details for the Nikkah and Reception ceremonies.
- **Responsive & Modern Design:** Thoughtfully designed for both mobile and desktop with sleek transitions, beautiful typography, and harmonious colors.

## 🛠️ Technology Stack

- **HTML5:** Semantic structure for optimal accessibility and SEO.
- **Vanilla CSS3:** Utilizing advanced features like CSS Variables, Grid, Flexbox, and complex animations without the bloat of frameworks.
- **Vanilla JavaScript (ES6+):** Handling interactivity (sound toggling, scratch-reveal logic, countdown timer) without external dependencies.

## 🚀 Getting Started

Simply open `index.html` in your browser to view the invitation, or host the files on any static web hosting platform (e.g., GitHub Pages, Netlify, Vercel).
